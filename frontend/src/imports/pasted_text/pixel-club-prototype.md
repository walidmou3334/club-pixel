Create a complete high-fidelity interactive website prototype for a student gaming and entertainment club called PIXEL.

IMPORTANT:
PIXEL IS A STUDENT CLUB, NOT A SOFTWARE COMPANY, NOT A DEVOPS PLATFORM, NOT A SAAS PRODUCT AND NOT A TECH DASHBOARD.

The uploaded Pixel logo is the official logo. Use it as the main visual identity.

==================================================
1. PROJECT CONTEXT
==================================================

Pixel is a student club founded in 2025.

The club brings together students interested in:
- Online video games
- Esports
- Casual gaming
- Board games
- Card games
- Gaming sessions
- Social activities
- Tournaments
- Entertainment

Pixel is still a young club with only one year of existence.

The website must therefore feel like:
“A young gaming community that is growing and building its identity.”

Do NOT invent hundreds of members, dozens of events, fake statistics, fake achievements or a huge esports history.

The website should be exciting and ambitious while remaining authentic.

CORE BRAND MESSAGE:

PIXEL

PLAY. CONNECT. CREATE.

“Every player is a piece of Pixel.”

==================================================
2. VISUAL IDENTITY
==================================================

Use the uploaded Pixel logo as the primary visual reference.

The logo contains:
- Black circular background
- Pink / magenta
- Purple
- Blue
- Geometric pixel / puzzle-inspired shapes

Build the entire visual identity around these elements.

DESIGN STYLE:

- Premium dark gaming aesthetic
- Modern student community
- Minimal but immersive
- Glassmorphism used selectively
- Soft glow
- Rounded cards
- Thin borders
- Strong visual hierarchy
- Modern typography such as Inter, Space Grotesk or Satoshi
- Subtle pixel and puzzle motifs
- Smooth micro-interactions
- Elegant animations
- High contrast
- Professional enough for an official school club

DO NOT:
- Make it look like a corporate SaaS dashboard
- Make it look like a DevOps dashboard
- Use deployments, commits, bandwidth, cloud metrics or software terminology
- Overuse neon
- Make it childish
- Make it look like a generic esports template
